### `03 — Featured Engineering Projects`

- **[Analog Buck Converter for the Raspberry Pi 5](https://github.com/yassinechouk/analog-buck-pi5)** — A 5 A power supply for the Pi 5, built from analog circuitry only (no MCU, no controller IC), with overvoltage and short-circuit protection. Simulated in LTspice, designed in KiCad.
- **[FreeRTOS Inspector](https://github.com/yassinechouk/Freertos-inspector)** — A tool to watch FreeRTOS tasks and measure real-time timing, validated on hardware.
- **[STM32 Dual-Slot OTA Bootloader](https://github.com/yassinechouk/BOOTLOADER_OTA)** — A bare-metal bootloader for safe over-the-air updates, with image checks and automatic rollback.
- **[TI C2000 Motor Control](https://github.com/yassinechouk/c2000-vf-motor-control)** — V/f control of a three-phase motor on a TI C2000 DSP, with PWM generation for the inverter.
